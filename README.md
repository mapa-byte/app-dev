# Psycho-Pass (2012)
 
**Psycho-Pass** is a gripping cyberpunk psychological thriller anime set in a dystopian future where society is governed by the Sibyl System. This advanced network continuously measures a citizen's mental state and likelihood to commit crimes, known as their **Psycho-Pass**.
 
## Key Highlights
* **Genre:** Cyberpunk, Psychological Thriller, Sci-Fi
* *Protagonist:* Akane Tsunemori
* **Core Theme:** Justice, morality, and free will in a technologically controlled world
